# Crawler policy for the CSU Climate Faculty Directory.
#
# IMPORTANT: robots.txt is only honoured at a DOMAIN root. This file deploys to
# https://csu-climate.github.io/directory/robots.txt, which crawlers ignore --
# they read https://csu-climate.github.io/robots.txt and nothing else. It takes
# effect only if the site moves to its own domain. See CLAUDE.md.
#
# Note also that robots.txt is a request, not a control. Well-behaved crawlers
# honour it; email harvesters do not. The addresses on this site are protected
# by being encoded and revealed only on click, not by anything in this file.

# Search engines are welcome, including members.json. The page renders every
# member card from that file, so blocking it would leave an empty shell in the
# index and make the directory unfindable -- the opposite of the point.
